# Инструкция по использованию скриптов для рассылок в Telegram

Здесь описаны три инструмента для взаимодействия с пользователями Telegram от имени бота: для подготовки кампаний, для массовых рассылок и для отправки одиночных сообщений.

## Подготовка к работе

Перед запуском любого из скриптов убедитесь, что:

1.  **Вы находитесь в корневой директории проекта**:
    ```bash
    cd /path/to/your/flirtello-backend-service
    ```
2.  **Активировано виртуальное окружение**: У вас должно быть настроено и активировано окружение (`venv` или `conda`), в котором установлены все зависимости из `src/requirements.txt`.
3.  **Настроен файл `.env`**: Скрипты используют те же файлы конфигурации, что и основной проект, для получения токенов и URL. Убедитесь, что `src/telegram/.env.telegram`, `src/.env.dev` и другие необходимые `.env` файлы существуют и содержат корректные данные (`TELEGRAM_BOT_TOKEN`, `MARKETING_API_URL`, `MARKETING_API_KEY`).

## 1. `prepare_campaign.py` - Подготовка кампании

Этот скрипт используется для подготовки CSV-файла с пользователями для массовой рассылки.

**Назначение:**

*   Выполняет SQL-запрос к базе данных для получения списка пользователей (`user_id` и `user_uuid`).
*   Создает CSV-файл, готовый для использования в `bulk_sender.py`.

**Настройка:**

Вся конфигурация задается непосредственно в переменных внутри скрипта `src/telegram/prepare_campaign.py`:
-   SQL-запрос для выборки аудитории.
-   URL поста для рассылки.
-   Текст и URL для кнопки.
-   Тег кампании (`campaign_tag`).
-   Имя выходного файла.

**Пример выходного CSV-файла:**

**Как использовать:**

Просто запустите скрипт. Он не принимает аргументов командной строки.
```bash
python src/telegram/prepare_campaign.py
```

**Пример создаваемого CSV-файла:**

```csv
telegram_id,user_id,campaign_tag,post_url,button_text,button_url
12345678,aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee,special_promo_2024,https://t.me/c/123/456,Click me,https://example.com
87654321,ffffffff-gggg-hhhh-iiii-jjjjjjjjjjjj,special_promo_2024,https://t.me/c/123/456,Click me,https://example.com
```

## 2. `bulk_sender.py` - Массовая рассылка

Основной инструмент для проведения массовых рассылок по пользователям из CSV-файла.

**Ключевые особенности:**

-   **Работа по CSV-файлу**: Удобное управление списком получателей.
-   **Интеграция с маркетинговой системой**: Автоматически отправляет событие после успешной доставки сообщения.
-   **Идемпотентность и отказоустойчивость**: Если скрипт прервется, его можно безопасно запустить снова. Он не будет повторно отправлять сообщения или события, которые уже были успешно обработаны, а доделает только проваленные шаги.
-   **Подробный отчет**: По окончании работы создается файл с результатами, где указан статус отправки для каждой строки.
-   **Регулируемая задержка**: Позволяет избежать превышения лимитов Telegram API.
-   **Тестовый режим (`dry-run`)**: Позволяет запустить скрипт для проверки данных и логики без реальной отправки сообщений и без изменения файла с результатами.

### Как использовать

#### Шаг 1: Подготовьте CSV-файл

Используйте `prepare_campaign.py` или создайте файл вручную. 
- Обязательные колонки: `telegram_id`, `user_id`, `post_url`.
- Необязательные колонки: `button_text`, `button_url`, `campaign_tag`.

#### Шаг 2: Запустите скрипт

Выполните команду, указав путь к вашему файлу.

**Аргументы командной строки:**

-   `csv_path` (обязательный, позиционный): Путь к CSV-файлу.
-   `--delay` (необязательный): Задержка между отправками в секундах. По умолчанию `1`.
-   `--dry-run` (необязательный): Запускает скрипт в тестовом режиме. Скрипт прочитает существующий файл с результатами для симуляции реального запуска (покажет, какие задачи были бы пропущены), но не будет отправлять сообщения или события и не будет изменять файл результатов. В консоль выводится подробная информация о том, что и кому должно было быть отправлено.

**Примеры запуска:**

-   **Стандартный запуск:**
    ```bash
    python src/telegram/bulk_sender.py data/campaign_special_promo.csv
    ```

-   **Тестовый запуск (`dry-run`):**
    ```bash
    python src/telegram/bulk_sender.py data/campaign_special_promo.csv --dry-run
    ```

#### Шаг 3: Проверьте результаты

Скрипт создаст (или дополнит) файл с результатами `[имя_кампании]_results.csv` (например, `campaign_special_promo_results.csv`).

В файле будут исходные колонки плюс четыре новые:
-   `message_sent_at`: Время отправки сообщения.
-   `message_status`: Статус (`ok` или текст ошибки от Telegram).
-   `event_sent_at`: Время отправки маркетингового события.
-   `event_status`: Статус (`ok` или текст ошибки от API).

## 3. `sender.py` - Одиночная отправка

Простой скрипт для отправки одного сообщения конкретному пользователю.

### Как использовать

**Аргументы командной строки:**

-   `--user-id` или `--username` (обязательный): ID или `@username` получателя.
-   `--post-url` (обязательный): URL-адрес поста для копирования.
-   `--button-text`, `--button-url` (необязательные): Текст и URL для кнопки.

**Примеры запуска:**

-   **Минимальный пример (по `user_id`):**
    ```bash
    python src/telegram/sender.py --user-id 123456789 --post-url https://t.me/c/1234567890/123
    ```

-   **Минимальный пример (по `@username`):**
    ```bash
    python src/telegram/sender.py --username some_user --post-url https://t.me/c/1234567890/123
    ```

-   **Пример с добавлением кнопки:**
    ```bash
    python src/telegram/sender.py --user-id 123456789 --post-url https://t.me/c/1234567890/123 --button-text "Посетить сайт" --button-url "https://flirtello.ai"
    ```
