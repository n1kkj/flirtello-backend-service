# Как начать работу над задачей

Эта инструкция описывает шаги для подготовки рабочего пространства перед началом работы над задачей из Asana.

## Алгоритм действий

### 1. Получите задачу из Asana через MCP

**КРИТИЧНО:** Если подключение к Asana не работает, процесс должен завершиться с ошибкой.

**Шаги:**
1. Получить список workspace: `mcp_asana_asana_list_workspaces()`
2. Найти задачу через typeahead: `mcp_asana_asana_typeahead_search(workspace_gid, resource_type="task", query="TASK-ID")`
3. Получить детали задачи: `mcp_asana_asana_get_task(task_id=task_gid)`

**Что извлечь:**
- `task_id` (например, "AL-133")
- `name` (название задачи)
- `notes` или `html_notes` (описание задачи)

**Обработка ошибок:**
- Если Asana MCP недоступен → **ERROR: Не удалось подключиться к Asana MCP**
- Если задача не найдена → **ERROR: Задача TASK-ID не найдена в Asana**

### 2. Создайте структуру папок

```bash
mkdir -p tasks/TASK-ID/artifacts
```

**Результат:**
```
tasks/
└── TASK-ID/
    └── artifacts/
```

### 3. Создайте файл `TASK-ID-task.md`

**Структура файла:**

```markdown
# TASK-ID: Название задачи

## Описание задачи

[Описание из Asana - поле notes или html_notes]

## Чеклист

- [ ] Понял задачу
- [ ] Изучил код
- [ ] Реализовал решение
- [ ] Протестировал
- [ ] Создал Result.md
- [ ] Создал Findings.md
- [ ] Организовал артефакты (если были)
- [ ] Обновил руководства (если нужно)

## Заметки

[Ваши заметки в процессе работы]
```

**Заполнить:**
- Название задачи из Asana (`name`)
- Описание задачи из Asana (`notes` или `html_notes`)

## Пример

**Ввод:** "Начни задачу AL-133"

**Действия:**
1. Получить задачу AL-133 из Asana через MCP
2. Создать `tasks/AL-133/artifacts/`
3. Создать `tasks/AL-133/AL-133-task.md` с названием и описанием из Asana

## Обработка ошибок

**КРИТИЧНО:** Если не удается подключиться к Asana, завершить с ошибкой:

```
ERROR: Не удалось подключиться к Asana MCP. Проверьте:
1. Настроен ли Asana MCP сервер
2. Корректен ли API ключ
3. Доступен ли интернет

Задача не может быть начата без доступа к Asana.
```

## Следующие шаги

После создания структуры:
1. Изучите описание задачи в `TASK-ID-task.md`
2. Изучите связанный код
3. Начните работу над задачей
4. Обновляйте чеклист в `TASK-ID-task.md` по мере прогресса
5. При завершении следуйте инструкции из `finalization.md`
