# AL-143: Расширить команду /me333, добавить отображение текущего channel_id

## Задача

Расширить команду `/me333` для отображения текущего `channel_id` пользователя в JSON-ответе.

## Что сделано

### 1. Добавлено отображение channel_id

**Проблема:** Команда `/me333` не показывала текущий `channel_id`, что затрудняло отладку.

**Решение:**
- Добавлена логика получения `channel_id` через запрос к таблице `channels`
- Запрос использует `active_char_id`, `user_id` и `config_id` для поиска соответствующего канала
- Добавлено поле `channel_id` в JSON-ответ команды

### 2. Исправлена обработка NULL значений

**Проблема:** Команда не находила каналы, когда `config_id` был `NULL` как в канале, так и в настройках пользователя.

**Решение:**
- Убрана проверка `current_config_id_from_settings` из условия `if` (теперь проверяется только `active_char_id`)
- Добавлена правильная обработка NULL значений для `config_id`:
  - Если `config_id` не `None` → используется сравнение на равенство
  - Если `config_id` равен `None` → используется проверка `Channel.config_id.is_(None)`

## Верификация
