# AL-144: Исправление непереведенного сообщения об ошибке и улучшение обработки 429 ошибок от Telegram API

## Описание задачи

При запросе картинки пользователь получал непереведенное сообщение об ошибке "Something went wrong while preparing your request. Please try again. ❤️" на английском языке, даже если язык интерфейса был русским.

Также обнаружена проблема с обработкой ошибок 429 (Too Many Requests) от Telegram API при отправке placeholder анимации - процесс генерации иллюстрации прерывался, хотя можно было использовать fallback на текстовое сообщение.

## Проблемы

1. **Непереведенное сообщение об ошибке:**
   - Сообщение "Something went wrong while preparing your request. Please try again. ❤️" отсутствовало в файлах локализации
   - Пользователи с русским языком видели английский текст

2. **Проблема с 429 ошибками:**
   - При превышении лимита запросов к Telegram API (429 Too Many Requests) процесс генерации иллюстрации полностью прерывался
   - Не использовался fallback на текстовое сообщение
   - Пользователь получал ошибку вместо продолжения процесса

3. **Неоптимальная обработка Retry-After:**
   - При получении 429 ошибки не использовался заголовок `Retry-After` от Telegram API
   - Использовалась фиксированная задержка, что могло приводить к повторным ошибкам

## Заметки

**Найденные в логах New Relic:**
- Множественные ошибки "429 Too Many Requests" при отправке placeholder анимации
- Ошибки "Failed to send placeholder message" следовали сразу после 429 ошибок
- Проблема возникала регулярно, особенно в периоды высокой нагрузки

**Решение:**
- Добавлены переводы для сообщения об ошибке
- Реализован fallback на текстовое сообщение при ошибке отправки анимации
- Улучшена обработка 429 с использованием Retry-After заголовка и экспоненциальной задержки
